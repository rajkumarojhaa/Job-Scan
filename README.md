# Job Scan 🧑‍💼🔍

**Job Scan** is a MERN stack-based job portal application that connects job seekers and recruiters. It enables students to register, browse and apply for jobs, while recruiters can post jobs, manage applicants, and monitor responses — all in a seamless user experience.

## 🚀 Features

### 👨‍🎓 Student Panel
- Register/Login
- Browse available jobs
- View job details
- Apply for jobs
- Track application status

### 🧑‍💼 Recruiter Panel
- Register/Login
- Post new jobs
- View and manage posted jobs
- View list of applicants per job



## 🧩 Tech Stack

| Tech       | Description                    |
|------------|--------------------------------|
| **MongoDB**| NoSQL database for storing data|
| **Express**| Backend framework for Node.js  |
| **React**  | Frontend library               |
| **Node.js**| Server-side JavaScript runtime |
| **Redux**  | State management (for job & auth states) |
| **Tailwind CSS** | Utility-first styling for UI |
| **Cloudinary** | (optional) File uploads for resumes |


## 🔐 Authentication & Security
- JWT-based authentication
- Role-based access (Student, Recruiter, Admin)
- CORS and cookie handling for secure sessions
